# Predio de Diabetes com Machine Learning
# 🩺 Diabetes Prediction Project

Este repositório faz parte de um **projeto acadêmico da faculdade**, desenvolvido com o objetivo de aplicar conceitos de **Machine Learning** para a **previsão precoce de diabetes** a partir de dados clínicos reais e simulados.  

O projeto envolve todas as etapas de um pipeline de ciência de dados: coleta, limpeza, análise exploratória, modelagem e avaliação de desempenho.

---

## 🎯 Objetivo

Desenvolver um modelo de **classificação binária** (Diabético / Não Diabético) com base em variáveis clínicas

O intuito é compreender como essas variáveis influenciam o risco de diabetes e explorar como o **aprendizado de máquina** pode auxiliar na prevenção e diagnóstico precoce.
